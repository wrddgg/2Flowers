## 5. 对“流程是否自然”的判断

结论：**整体自然，主链路成立，但场景转译还可以再克制一些。**

具体判断如下：

1. 输入到参考的映射是自然的。  
   雨夜窗边的安静、克制、轻治愈，被映射到蓝白克制花束，这个方向在情绪和视觉上是通顺的。

2. 参考到成品的映射大体自然。  
   生成图延续了参考图的蓝白、留白、包装感，也保留了输入图的治愈与安静，不像完全跑偏的“另一个产品”。

3. 目前最值得注意的问题，是生成图仍然带有较强的“场景直译”倾向。  
   反向语义复核里，3 张生成图仍被识别出明显的 `窗边 / 雨天 / 室内` 标签，这说明模型有一定概率把输入场景直接画进成品图，而不是只把场景气质翻译成花束。

4. 结果多样性偏弱。  
   3 张生成图的语义几乎完全一致，说明当前 prompt 更偏“稳”，但在 demo 展示层面会显得变化不够大。后续可以通过更明确的“同主题不同方案”约束来提升差异性。

## 6. 本轮已做的纠偏

针对上面的自然度问题，我已在代码里优化 prompt，核心方向是：

- 明确要求 `scene` 输入必须“转译成花束”，不要直接复现原始空间
- 把参考约束改成“借鉴颜色、结构、包装气质”，而不是模糊的“参考一下”
- 把负向约束真正写进最终生图 prompt，避免人物、桌面陈列、花瓶、插画感和直接翻版
- 让语义识别更关注“可被转成花艺方案的语义”，而不是泛描述

## 7. 建议

短期建议：

- 继续保留当前蓝白雨夜样例，作为正式版本标准回归样本
- 下一轮增加 1 个 `life` 样例和 1 个 `flower` 样例，检查不同 mode 下的自然度
- 若想提升 3 图差异度，可在生图 prompt 里加入“分别偏轻包装 / 偏空气感 / 偏层次感”的多样性约束

中期建议：

- 在生成后增加一次“反向语义打分”，判断生成图是否过度复现了原始场景
- 若场景标签在成品图里过重，可自动降低 scene 直译权重
